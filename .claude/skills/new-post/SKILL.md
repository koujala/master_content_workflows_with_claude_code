# new-post

Create one topic folder under `/posts`. This skill holds all the conventions for the project.

## Folder layout and naming

Each topic is one folder under `/posts`. The folder name is the topic in snake_case, 3-4 words. Every file uses the exact folder name as its prefix.

```
/posts/<name>/
    <name>.png          placeholder image (1280x720, 16:9); later overwritten by a GPT image with the same filename
    <name>.md           short form (no _short suffix)
    <name>_long.md      long form
    <name>_prompt.md    image-generation prompt
    <name>.json         metadata for the root index.html (see Files)
```

`/index.html` is the browsable view of all posts. It reads `/posts-data.js`, generated by `/.claude/hooks/build_index.py` from every `<name>.json`.

## Input

A topic, e.g. `/new-post Vertical Slicing Architecture`.

If no topic is given, or the user asks for suggestions, propose 5 topics (IT and software engineering) that don't already exist in `/posts`, and let the user pick. Don't start writing until a topic is chosen.

## Steps

1. **Name:** turn the topic into a snake_case name of 3-4 words (`vertical_slice_architecture`). If a folder with that name already exists in `/posts`, stop and ask.
2. **Research:** use WebSearch for current, accurate facts. Don't invent claims.
3. **Create** `posts/<name>/` with the four files below. Every file name starts with the exact folder name.
4. **Placeholder PNG:** generate a 1280x720 image with the Python helper below.
5. **Metadata:** write `<name>.json` (below), then the project's PostToolUse hook runs `.claude/hooks/build_index.py --hook` automatically to refresh `posts.json` and `posts-data.js`. Run `python .claude/hooks/build_index.py` yourself only if the files look stale.
6. **Verify** the body character counts, then report them with links to the files.

## Files

- `<name>.md`: short form, ~500 chars of body, plain prose. Starts with the image `![Title](<name>.png)`.
- `<name>_long.md`: long form, ~1000 chars of body in total. Sections in this order, each with an emoji heading:
  1. `# <emoji> Title`
  2. image `![Title](<name>.png)`
  3. `### <emoji> Subtitle`
  4. `## 📖 Main Content`
  5. `## 🔑 Key Concepts` (bullets, emoji plus bold term)
  6. `## 💡 Key Takeaways` (bullets with emojis)
  7. `## ✨ One-Line Summary`
- `<name>_prompt.md`: the GPT image prompt only. No heading, comments or explanation. It must specify:
  - 16:9, simple and professional
  - a 2x2 card grid, a 3x3 card grid, or a 3-card transition layout, whichever fits the topic
  - realistic Indian, Japanese or South American men and women working in IT
  - no logos or watermarks
- `<name>.png`: placeholder.
- `<name>.json`: metadata, these fields only:
  ```json
  {"title": "", "emoji": "", "subtitle": "", "summary": "<the one-line summary>", "category": "", "tags": [], "created": "YYYY-MM-DD", "status": "draft"}
  ```
  Reuse an existing category from the other posts' json where one fits (check before inventing a new one). Tags are lowercase, hyphenated, 3-6 of them. `status` is `draft`, and the user moves it to `published`.

## Placeholder PNG

```
python .claude/hooks/post_tools.py png <name> "<Title>"
```

Writes `posts/<name>/<name>.png` (requires Pillow).

## Character check

Count body text excluding the image line:

```
python .claude/hooks/post_tools.py count <file> [<file>...]
```

Stay within roughly ±10% of the targets (500 short, 1000 long). Trim or expand and recheck if outside.
